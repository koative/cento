# Koative Templates

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-authorized React, Vite, Tailwind CSS and Bun. Static builds for GitHub Pages. Separate template folders in a single repository.

## Users

Developers and designers browsing reusable website starting points (inferred from gallery and repository request).

## Product Purpose

Publish a growing collection of distinctly designed website templates, each with its own structure, sector and animation language, through a gallery. The user subsequently confirmed https://koative.github.io/templates/ as the publishing destination and instructed us not to change koative.com settings.

## Capabilities and Constraints

Twelve templates in the first collection; the user requested twelve additional templates, bringing the total to twenty-four. Responsive, keyboard-accessible previews, source links and independently buildable folders. Static demonstration interactions only; no backend or payment processing requested. User explicitly delegates creative orchestration and parallel implementation to agents. Preserve the existing koative.com site.

## Brand Commitments

Koative. All UI and documentation in English, confirmed by user. Bold visual diversity including 3D and animation. Impeccable informs craft without limiting creativity.

## Evidence on Hand

Empty workspace. Authenticated GitHub account with koative organization. No supplied commercial photography, customer claims or testimonials. Template businesses and data must be identified as fictional demonstrations.

## Product Principles

- Distinct compositions, not color-swapped copies.
- Each template is usable outside the gallery.
- Motion enhances identity and respects reduced-motion preferences.
- Make exploration and source access immediate.

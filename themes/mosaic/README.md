# Mosaic

A material-led interiors studio with a live sample library and room moodboard.

[Live demo](https://koative.github.io/templates/themes/mosaic/)

## Run independently

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. The relative Vite base supports nested hosting. This folder is self-contained.

## Design and interaction

Material studio: architectural photo composition, floating material slab, earthy swatches and a room brief.

Material selection, add/remove moodboard samples, room selection and brief save. All state is local to the current page visit and resets on reload. All businesses, products, prices, schedules and services are fictional. No order, payment, booking or inquiry is sent.

## Customize

Edit `src/App.tsx` for content and behavior, `src/styles.css` for the visual system, and `index.html` for metadata. React 19, TypeScript and Vite. Semantic controls, visible keyboard focus, mobile reflow and reduced-motion handling are included.

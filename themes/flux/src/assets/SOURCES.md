# Asset sources

Flux is a graphic theme: it ships no raster images.

- All graphics are authored SVG/CSS in this template: the Flux logo and favicon, the 17 connector marks (`src/components/Marks.tsx`), the flow canvas and its wires, the run-volume chart, the About diagram and the 404 illustration. Code MIT.
- Icons: [Lucide](https://lucide.dev/) via `lucide-react`, ISC license.
- Fonts: [Wix Madefor Display](https://fonts.google.com/specimen/Wix+Madefor+Display) and [Wix Madefor Text](https://fonts.google.com/specimen/Wix+Madefor+Text) by Wix.com, SIL Open Font License 1.1, loaded from Google Fonts.
- All connector names (Hallway, Ledgerline, Coinpost…), companies and people are fictional.

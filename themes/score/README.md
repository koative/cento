# Score

An inviting music practice room with a playable piano and a personal lesson finder.

[Live demo](https://koative.github.io/templates/themes/score/)

## Run independently

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. The relative Vite base supports nested hosting. This folder is self-contained.

## Design and interaction

Practice room: midnight blue and warm keys, Space lettering, playable octave, phrase strip and lesson finder.

User-triggered Web Audio notes, phrase reset, instrument/level choice and saved lesson plan. All state is local to the current page visit and resets on reload. All businesses, products, prices, schedules and services are fictional. No order, payment, booking or inquiry is sent.

## Customize

Edit `src/App.tsx` for content and behavior, `src/styles.css` for the visual system, and `index.html` for metadata. React 19, TypeScript and Vite. Semantic controls, visible keyboard focus, mobile reflow and reduced-motion handling are included.

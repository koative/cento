# Sonnet

A conversational language school with rotating word cards and a course-plan builder.

[Live demo](https://koative.github.io/templates/themes/sonnet/)

## Run independently

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. The relative Vite base supports nested hosting. This folder is self-contained.

## Design and interaction

Language workbook: typographic vocabulary card, coral and sage paper, conversational sentence-based course planning.

Language switching, starting level, weekday choice and saved learning plan. All state is local to the current page visit and resets on reload. All businesses, products, prices, schedules and services are fictional. No order, payment, booking or inquiry is sent.

## Customize

Edit `src/App.tsx` for content and behavior, `src/styles.css` for the visual system, and `index.html` for metadata. React 19, TypeScript and Vite. Semantic controls, visible keyboard focus, mobile reflow and reduced-motion handling are included.

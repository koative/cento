# Oddbox / Arcade design

Mode: Experience with a functional game at its center.

An indie game studio with a playable browser memory game, tactile lilac game cabinet, playful catalog artwork, and an orange studio introduction.

## Tokens

Cream #faf2de / purple #6848bd / candy pink #edc6e6 / orange #e98c5d.

Typography: Space Grotesk and DM Sans. Display tracking never below -0.04em. Desktop display is capped at 96px.

## Composition and behavior

Pair Up is a working randomized memory game with six pairs, move count, match state, keyboard support, and reset. Read expandable game concepts and try a clearly disclosed local demo email form. No information is collected.

The mobile composition reflows into one column at 760px (750px for Vélo). Decorative perspective responds to hover only where useful. Continuous motion is initiated by the visitor; reduced-motion preferences disable transitions and animation.

## Provenance

All game symbols are Lucide icons (ISC); all cabinet and catalog graphics are original CSS. No third-party images or audio.

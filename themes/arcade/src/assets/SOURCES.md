# Sources

## Images

None. Every picture in this template is authored in code:

- Game key art and screenshots: pixel scenes generated on a 160×90 grid by `src/components/Scene.tsx` from the palettes in `src/content.ts`.
- Sprites (Blob, thistles, bees, ships, lighthouse, fish, cat, washers, kites, cards): hand-drawn letter grids in `src/lib/pixels.ts`.
- Team portraits and the logo mark: pixel grids in `src/components/PixelArt.tsx`.
- Blob Hop demo: drawn on a 192×108 canvas by `src/lib/blobhop.ts`.
- Favicon: inline SVG in `index.html`.

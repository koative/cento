# Truffle

A chocolate atelier with a dimensional gift box and a six-piece flavor composer.

[Live demo](https://koative.github.io/templates/themes/truffle/)

## Run independently

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. The relative Vite base supports nested hosting. This folder is self-contained.

## Design and interaction

Chocolate atelier: cocoa and parchment, angled six-piece box, flavor menu and empty-to-complete gift composition.

Add/remove chocolates, six-piece limit, completion gating and local saved box. All state is local to the current page visit and resets on reload. All businesses, products, prices, schedules and services are fictional. No order, payment, booking or inquiry is sent.

## Customize

Edit `src/App.tsx` for content and behavior, `src/styles.css` for the visual system, and `index.html` for metadata. React 19, TypeScript and Vite. Semantic controls, visible keyboard focus, mobile reflow and reduced-motion handling are included.

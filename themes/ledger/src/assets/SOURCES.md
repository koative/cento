# Asset sources

Ledger uses no photography. Every graphic is authored for this template:

- Logo mark, favicon and the ruled card pattern — inline SVG.
- Debit card — CSS gradients and SVG rules (`src/components/DebitCard.tsx`).
- Spending pace and balance charts — SVG drawn from demo data (`src/components/Charts.tsx`).
- Meters, allocation bars and net-worth bars — CSS.

Fonts: Plus Jakarta Sans (Tokotype), SIL Open Font License 1.1, via Google Fonts.
Icons: Lucide, ISC License.

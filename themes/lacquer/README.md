# Lacquer

An expressive color studio with sculptural nail samples, finishes and service planning.

[Live demo](https://koative.github.io/elseform/themes/lacquer/)

## Run independently

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. The relative Vite base supports nested hosting. This folder is self-contained.

## Design and interaction

Nail color studio: rose and burgundy, glossy sculptural color samples, shade strip and a personal appointment card.

Five shades, gloss/matte finish, three services and a locally saved look. All state is local to the current page visit and resets on reload. All businesses, products, prices, schedules and services are fictional. No order, payment, booking or inquiry is sent.

## Customize

Edit `src/App.tsx` for content and behavior, `src/styles.css` for the visual system, and `index.html` for metadata. React 19, TypeScript and Vite. Semantic controls, visible keyboard focus, mobile reflow and reduced-motion handling are included.

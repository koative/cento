# Botanica

An independent **botanical garden** template from Koative. Get wonderfully lost. A botanical field guide and seasonal garden explorer.

## Run

```sh
bun install
bun run dev
```

Build with `bun run build`; preview with `bun run preview`. React, TypeScript and Vite. Relative assets support static subdirectory hosting.

## Customize

Edit `src/App.tsx` for content and local interactions, `src/styles.css` for the design, and `src/assets` for imagery. No backend or shared runtime dependency.

## Demonstration

All brands, prices, programmes and content are fictional. Interactions update local state for this visit, reset on reload and do not make bookings, process payments, send messages or offer professional advice. Keyboard focus, reduced motion and mobile layouts are supported.

## Assets

Self-hosted Google Fonts: DM Sans and Instrument Serif, with bundled OFL notices. Asset source URLs and local reuse origins are recorded in `src/assets/SOURCES.md`. Code: MIT.

## Interactions

Select garden trails, inspect their plants and save a walk.

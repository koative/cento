# Asset sources

Stack is a graphic theme. It ships no raster images.

| Asset                                                  | Source                                                     | Creator             | License                      |
| ------------------------------------------------------ | ---------------------------------------------------------- | ------------------- | ---------------------------- |
| Logo mark, favicon                                     | Authored SVG in `src/components/Logo.tsx` and `index.html` | Koative             | MIT (with the template code) |
| Job flow diagram, job lifecycle diagram, backoff chart | Authored SVG in `src/components/Figures.tsx`               | Koative             | MIT (with the template code) |
| Icons                                                  | [Lucide](https://lucide.dev/) via `lucide-react`           | Lucide contributors | ISC                          |
